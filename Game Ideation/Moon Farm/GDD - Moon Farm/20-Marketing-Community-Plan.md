
## 🔹 Marketing Goals

1. Build **awareness** of MOON as a cozy farming adventure with emotional depth.
2. Grow a **dedicated fanbase pre-launch** through transparent dev updates.
3. Establish **trust and goodwill** by emphasizing craftsmanship, narrative, and fair monetization.
4. Position MOON as a **premium indie title** for Switch & PC, with mobile as an accessible gateway.

## 🔹 Brand Positioning

| **Element**       | **Strategy** |
| ----------------- | ------------ |
| **Core Identity** | A magical, heartwarming life-sim where exploration and relationships matter. |
| **Tone of Voice** | Gentle, personal, story-driven. Avoid overly "corporate" messaging. |
| **Target Audience** | Cozy game fans, farming/life sim players, Switch owners, mobile casual gamers seeking premium depth. |
| **USP (Unique Selling Point)** | Emotional storytelling, deep farming & exploration mechanics, cross-platform accessibility. |

## 🔹 Key Milestones

| **Phase**                     | **Actions** |
| ----------------------------- | ----------- |
| **Pre-Alpha (6–12 Months Pre-Launch)** | Dev blog, concept art reveals, small devlog videos. |
| **Alpha/Closed Beta (3–6 Months Pre-Launch)** | Invite early fans, influencers, farming-sim communities. |
| **Launch Month**              | Nintendo Indie World or Steam Next Fest participation; influencer streams. |
| **Post-Launch (3–6 Months)** | Major patches, free seasonal content drops, reviews push. |

## 🔹 Community Building

| **Channel**            | **Purpose** |
| ---------------------- | ----------- |
| **Discord Server**     | Core fan hub, feedback loop, behind-the-scenes dev updates. |
| **Twitter/X**          | Art reveals, GIFs, cozy daily content. |
| **YouTube/Devlogs**    | Monthly progress updates to humanize the dev process. |
| **Instagram/TikTok**   | Quick, cozy farming clips, showing emotional worldbuilding moments. |
| **Reddit (r/CozyGames)** | Target cozy/life sim communities early. |

## 🔹 Marketing Beats

| **Beat**             | **Timing** |
| -------------------- | ---------- |
| **Announcement Trailer** | At least 9 months before launch. |
| **Steam Wishlist Campaign** | Begins after announcement, updated with every major milestone. |
| **Switch Feature Push** | Pitch for Nintendo Indie Direct ~6 months pre-launch. |
| **Influencer Seeding** | Hand-pick cozy game YouTubers and Twitch streamers 3 months pre-launch. |
| **Festival Demos**   | Steam Next Fest or mobile soft launch. |
| **Launch Cinematic Trailer** | Release week. |
| **Post-Launch Spotlight** | Showcase new content in seasonal updates. |

## 🔹 PR & Partnerships

- Partner with **cozy game influencers** for authentic word-of-mouth.
- Apply for **Nintendo Switch promotional events** (Indie World).
- Collaborate with **indie publisher partners** for Switch marketing push if needed.
- Potential cross-promotion with cozy game Discords and newsletters.

## 🔹 Long-Term Community Engagement
