# 🌟 Game Vision

The game should feel:
- Relaxing (ASMR tactile sounds, soft visuals)
- Rewarding (clear progress & unlocks)
- Expressive (décor, customization)
- Sticky (events, daily rewards, mastery loop)

## Audience
- Cozy/ASMR lovers
- Mobile simulation fans
- Bakery/food game audience (Bakery Story, Lemon Cake fans)
