Each clothing piece has:

- rarity
- brand
- tags
- style categories
- upgrade level
- event usefulness
This means clothes are actually **long-term assets.**

One of Glow’s smartest systems is clothing upgrades.

Higher levels increase outfit scores, making upgrades an important long-term progression system. Players often report that later stages become much easier if they’ve invested in upgrading versatile items.


So players constantly decide:

- Buy a new dress?
- Upgrade existing one?

### Players don’t simply wear clothes.

Every item contributes to an outfit score based on:

- required theme
- item rarity
- item level
- brand
- matching tags

This means the “best-looking” outfit isn’t always the highest-scoring one.
