# 🚀 Roadmap & Scope

## MVP (3 months)
- Core loop (5 recipes)  
- Basic décor (10 items)  
- 3 NPCs  
- Coins only  
- 1 theme  
- Daily rewards  

## Launch (6 months)
- 20 recipes  
- 50 décor items  
- 6 NPCs  
- Gems + coins  
- 3 themes  
- Seasonal event system  

## Post-Launch (Live Ops)
- Monthly new recipes  
- Seasonal packs  
- Special NPCs  
- Social features
