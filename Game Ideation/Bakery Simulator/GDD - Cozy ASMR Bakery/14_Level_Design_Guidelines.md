# 🏠 Level Design Guidelines

## 🎯 Goal
Bakery should feel like a **single cozy room** the player expands over time.  
Easy to decorate, clear tile rules, never overwhelming.

---

## 📐 Layout Rules
- **Isometric grid**: Start with **5x5 tiles** (expand to 10x10 with progression).
- **Tile placement**: furniture & décor always snap to tiles.
- **Entrance**: NPCs spawn at bakery door → path to tables → exit after eating.
- **Stations**: ovens, counters, and decorations placed by player.

---

## 🏗️ Expansion
- Players start with a **small corner bakery** (limited space).
- Expansions unlock at level milestones (new 1–2 tile strips).
- Each expansion comes with **visual growth** (extra window, new wall section).

---

## 📑 Example Layout Stages

### Stage 1 (Starter Bakery)
- 5x5 grid  
- 1 oven, 1 counter, 1 table + 2 chairs  
- Wooden floor, pastel wall  

### Stage 2 (First Expansion)
- 7x5 grid  
- 2 ovens, 2 counters, 3 tables + 6 chairs  
- Add décor (poster, lamp, plant)  

### Stage 3 (Cozy Café)
- 10x10 grid  
- 3–4 ovens, 3 counters, 5 tables + 10 chairs  
- Themed décor pack (seasonal walls, fairy lights)  

---

## 📌 Greybox Workflow
- Devs prototype with **colored boxes** (blue = table, green = oven, red = door).  
- Artist replaces greyboxes with polished assets once layout is proven.
