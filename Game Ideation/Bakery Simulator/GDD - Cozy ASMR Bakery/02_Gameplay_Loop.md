# 🔄 Core Gameplay Loop

1. **Collect Orders** (NPCs request pastries)  
2. **Bake** (ingredient prep → mixing → baking → decorating)  
3. **Serve** (deliver pastry to NPCs)  
4. **Earn Rewards** (coins, XP, possible gems)  
5. **Customize** (buy décor, expand bakery)  
6. **Progression** (unlock recipes, themes, expansions)  

## Meta Loops
- **Mastery Loop** → Re-bake recipes to earn mastery bonuses  
- **Décor Loop** → Collect and place furniture & themes  
- **Retention Loop** → Daily login streak, events, seasonal recipes
